# Study folder: every decision, derivation and result

Read in this order to prepare for the presentation:

1. `glossary.md`: the vocabulary (nice, retaliatory, δ, ε, replicator dynamics, …).
2. `theory_derivations.md`: benchmarks B1–B6, derived step by step.
3. `M1_engine_and_strategies.md` … `M7_*.md`: one file per milestone covering what was
   built, how it works, the results and what they mean.
4. `decisions.md`: every design choice and why it was made (examiners often ask "why did you
   do X?").
5. `presentation_qa.md`: likely questions with answers.

Related folders:
- `../notes/predictions.md`: hypotheses, committed before any experiment ran.
- `../notes/findings.md`: each result as prediction → figure → agree/disagree → explanation.
- `../figures/`: all plots (PNG + PDF). `../results/`: raw CSVs and configs.
