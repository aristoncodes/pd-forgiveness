# Study folder: every decision, derivation and result

Read in this order to prepare for the presentation.

**1. The big picture (30 min)**
- `../notes/findings.md` → read the last section, "Answer to the title question", first.
- `presentation_outline.md`: the 12-slide plan with a figure and key sentence per slide.

**2. The theory (45 min)**
- `glossary.md`: vocabulary (nice, retaliatory, δ, ε, replicator dynamics, …).
- `theory_derivations.md`: benchmarks B1–B6 and the critical-mass formula, step by step.
  Be able to derive B1, B4 and B6 on a whiteboard.
